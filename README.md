# Jayesh Kulkarni's Portfolio

A modern, responsive developer portfolio built with React and Next.js, showcasing projects, skills, and experience. Features a beautiful dark/light mode toggle, animated sections, and a downloadable resume.

## 🚀 Features

- **Dark/Light Mode**: Easily switch between dark and light themes with a floating toggle button.
- **Responsive Design**: Looks great on all devices.
- **Animated Sections**: Smooth fade-in animations using `react-awesome-reveal`.
- **Downloadable Resume**: Download the latest resume with a single click.
- **Tech Stack Showcase**: Visual grid of technologies used, with modern SVG icons.
- **Contact Section**: Email and phone for easy reach.

## 🛠️ Tech Stack

- **Frontend**: React, Next.js, TypeScript, JavaScript, HTML5, CSS3, Tailwind CSS, MUI, Bootstrap
- **State Management**: Redux
- **Backend**: Node.js, Express.js
- **Database**: MongoDB, MySQL, Firebase
- **Other**: Framer Motion, React Icons

## 📦 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Jayeshkulkarni17/Portfolio.git
   cd Portfolio/portfolio
   ```
2. **Install dependencies:**
   ```bash
   npm install
   ```
3. **Start the development server:**
   ```bash
   npm start
   ```
4. **Open in browser:**
   Visit [http://localhost:3000](http://localhost:3000)

## 📄 Resume

You can download the latest resume directly from the [website](http://localhost:3000/Jayesh_Kulkarni.pdf) or from the [public folder](public/Jayesh_Kulkarni.pdf).

## 📁 Project Structure

- `src/Pages/` — Main pages (Home, About, Projects, Tech Stack, Contact)
- `src/Components/` — Reusable UI components (Navbar, Footer, etc.)
- `src/images/` — Tech stack and UI images
- `public/` — Static assets (resume, favicon, etc.)

## ✨ Customization

- **Update Resume**: Replace `public/Jayesh_Kulkarni.pdf` with your own.
- **Edit Projects**: Update `src/Components/Projects.js` with your own projects.
- **Change Tech Stack**: Edit `src/Pages/techStack.js` and add/remove technologies as needed.
